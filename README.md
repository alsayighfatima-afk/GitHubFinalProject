# Simple Interest Calculator

This project is a simple web-based calculator that computes simple interest based on the principal amount, annual interest rate, and time in years.

## Formula
The simple interest is calculated using the following formula:
**SI = (P × R × T) / 100**

Where:
* **P** = Principal amount
* **R** = Annual interest rate (in percentage)
* **T** = Time period (in years)

## Features
* Input fields for Principal, Rate, and Time.
* Instant calculation of simple interest.
* Clean and user-friendly interface.

## How to Use
1. Open the `index.html` file in any web browser.
2. Enter the Principal amount.
3. Enter the Rate of interest.
4. Enter the Time in years.
5. Click the "Calculate" button to view the result.
